Recap on Sling Model
1. Sling model is nothing but a java class
2. This java class is a helper for htl or sightly. That means business logic will move from sightly to Sling model.
3. To becomme a java pojo to sling model it should have @Model annotation on top of it.
4. This model should be mapped or Adapted to either a Resource or SlingHttpServletRequest.
5. It should have either @Inject or @ValueMapValue or both annotation on its variables which we want to inject from resource.
6. @PostConstruct method of sling model gets called automatically after injection.
7. We do not manually call or create ojbect of Sling model. It gets called from HTL or Sightly via data-sly-use
8. It should be having public getter methods so that these can be accesesed on HTL via variable names.

AEM Backend devlopment -> Services

1. OSGi Services
2. OSGi Components are java classes but they are smallest unit of OSGi architecture.
--------------------
Services, A java class to become a Service it should follow below criteria
 1. It should have @Component annotation on class.
 2. @Component annotation should have an attribute "service"
 3. It should always implement an interface
